## 0.1.0 — Unreleased

Initial standalone extraction of a project-local shared coding-agent register.

- Local SQLite task cards, exact file/directory claims, checkpoints, queued
  cross-identity notes, handoffs, and append-only completion corrections.
- Atomic claim batches, protection for existing Git changes, retained paused
  and stale ownership, and consistent read-only status/inbox snapshots.
- Generic identities for Codex, Claude Code, Antigravity, and other tools or
  parallel roles; Git-root discovery and explicit project/store selection.
- Dependency-free portable runtime and coordination skill, project installer,
  explicit upgrades, preserved existing instructions, and MIT licensing.
- Installable Python package, temporary-repository tests, independent-process
  concurrency checks, built-wheel smoke test, and a multi-platform CI workflow.

This version has not been published to GitHub or PyPI by the preparation task.
See `docs/validation.md` for actual local evidence and remaining platform checks.
